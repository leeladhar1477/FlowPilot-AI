# FlowPilot AI 🚀

FlowPilot AI is a Python-based browser automation project that automates WhatsApp messaging workflows using Selenium.

The project supports:
- Automated WhatsApp messaging
- Bulk messaging to multiple contacts
- Browser automation using Selenium
- Dynamic chat opening using WhatsApp direct links
- Automated workflow execution

---

# Features

## ✅ Single Contact Messaging
Automatically sends a WhatsApp message to a single contact.

## ✅ Bulk Messaging
Sends automated messages to multiple WhatsApp contacts sequentially.

## ✅ Browser Automation
Uses Selenium WebDriver for automating browser interactions.

## ✅ Dynamic Chat Automation
Automatically opens WhatsApp chats using direct URL-based automation.

## ✅ Error Handling
Handles loading delays and messaging failures gracefully.

---

# Technologies Used

- Python 3.11
- Selenium
- ChromeDriver
- WebDriver Manager
- WhatsApp Web
